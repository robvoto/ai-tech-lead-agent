# Completion Summary Rules

When summarizing a coding-agent run, keep the result short, plain-English, and phone-friendly.

- Say whether the run finished successfully, failed, or timed out.
- List changed files when available.
- Mention the most important outcome, not raw logs.
- Do not include secrets, raw prompts, or duplicated request bodies.
- If human acceptance is still required, say that clearly.
- If nothing changed, say that explicitly.
