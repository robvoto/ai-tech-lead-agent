# Backlog Ownership Rules

Backlog state is owned by the orchestrator and the human operator.
The Markdown backlog remains the source of truth for backlog items until the orchestrator accepts the work.

Worker coding agents must not mark backlog items complete, update Status, or update Validation unless the task explicitly says it is backlog/documentation maintenance.

Final backlog completion is owned by the orchestrator after human acceptance.

If a task needs backlog edits, the handoff must say so explicitly and the orchestrator must keep the final decision and acceptance gate.
