## When to use

Use these standards before creating or restructuring:

- project setup
- docs
- AGENTS.md
- skills
- config
- runtime commands
- tests
- env examples
- packaging
- templates
- AI model/provider defaults
- cost logging
- human approval workflows
- long-running workflows

## Update rule

Google Docs are the source of truth.

If this project teaches a reusable lesson, update the canonical Google Docs and Standards Change Log first. Local repo docs should only point to, or deliberately export from, those canonical docs.
