# Skill: Bounded Delivery

Use for all coding-agent work regardless of target repo.

## Rules
- Keep the change small and directly tied to the task.
- Stop when the target repo rules conflict with the request instead of guessing.
- Report changed files and exact validation evidence.
- Prefer replacing wrong behavior over adding silent fallback behavior.
- If the task appears already done, say so clearly and stop.
